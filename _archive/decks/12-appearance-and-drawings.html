Looks, and physics

Colour and material are not the same thing

Colour

  • Select the part, open the View tab, set Shape Appearance.
  • For a whole assembly, set it on the link and tick override.
  • Group by function: frame red, tynes dark, wear parts bright.

Material

  • Select the body and open the Material panel.
  • Choose Steel.
  • This sets the density, so the weight FreeCAD reports means something.

Every weight quoted in this course came out of the model this way. That is the difference between modelling and drawing.

Getting a clean picture

Six steps, and the first one is the one students skip.

  1. Hide the sketches, datums and origin — select them and press Space
  2. Set the view0 for isometric
  3. Fit the model on screenV then F
  4. Tools › Save image
  5. Type the pixel size in yourself, do not accept the window size
  6. Pick the background: current, white, or transparent

Green sketch lines all over a finished part is the commonest fault in student work, and it takes one keystroke to fix.

Appearance and Drawings03 / 06

TechDraw

Making a drawing

TechDraw turns the model into a dimensioned sheet, and the views stay linked to the model.

  1. Switch to the TechDraw workbench
  2. Insert default page
  3. Select the body, then Insert view
  4. Or use Insert projection group for front, top and side together
  5. Set the scale on the page1:8 suits the frame
  6. Dimension it, then export as PDF

Change the model and the drawing updates, dimensions included — as long as they are attached to geometry rather than typed in as text.

Which format to send

FormatCarriesSend it for
STEPexact solids and coloursanything going to another CAD system
DXFflat outlineslaser and plasma cutting
STLa triangle mesh3D printing only
FCStdeverything, editablea colleague who has to change it

STEP throws away the history. The person receiving it gets the solid, not your sketches or your spreadsheet. That is usually what you want for a supplier, and a disaster for a colleague.
