Setting Up a Part01 / 06

Step one

Units first, before you draw

How to change them

  1. Open Edit › Preferences › General › Units
  2. Set the unit system to Imperial decimal
  3. Set decimals to 3
  4. Click OK. Every box now reads inches.

The tutorial works in inches, so we work in inches.

FreeCAD always stores lengths in millimetres inside the file. Changing the units only changes what you see and type. Your geometry does not move.

Do this before you draw anything. Changing units halfway through will not break the model, but every number you had in your head now reads differently.

Setting Up a Part02 / 06

The three levels

Document, body, feature

FreeCAD has three levels. Mixing them up is the commonest beginner mistake.

  • A document is the file. We use one file per part.
  • A body is one solid lump of metal. Two separate lumps need two bodies.
  • A feature is one operation: a pad, a pocket, a fillet. Features run in order.

New features go into whichever body is active. Double-click a body in the tree to make it active; its name goes bold.

Setting Up a Part03 / 06

Do it the same way every time

Starting a new part

Four steps, every time. Get into the habit.

  1. File › New
  2. Switch to the Part Design workbench
  3. Create body from the Helper toolbar
  4. Save straight away, with a real nameCtrl+S

Name files in build order: 01_frame, 02_tine01, and so on. It keeps the folder readable.

Setting Up a Part04 / 06

The trap that catches everyone

Which plane is which

FreeCAD nameFacesSolidWorks calls itWe use it for
XY planeupTopthe frame seen from above, tyne heads, bolt holes
XZ planeforwardFrontthe blade section, clamp holes
YZ planesidewaysRightevery side view: both tynes, both clamps

Every body starts with three planes. You draw your first sketch on one of them.

The names do not match SolidWorks. When the video says “select the Right plane”, you want YZ.

Our machine directions

  • X runs across the machine
  • Y runs front to back
  • Z is up
Setting Up a Part05 / 06

Offsets, not faces

Putting a sketch where you want it

A sketch does not have to sit on a plane. Give it an offset and it floats parallel to that plane.

  1. Make the sketch on an origin plane as usual
  2. Select it and open the Data tab
  3. Find Attachment Offset › Position
  4. Type the distance into zz = 2 in

You can also sketch straight onto a face of your part. Do not. Faces get renumbered when you change something upstream, and your sketch then attaches to the wrong one. Every sketch in this course sits on an origin plane.
