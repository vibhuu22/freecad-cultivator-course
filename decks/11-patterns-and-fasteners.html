Extent, not spacing

Linear pattern: the setting that matters

Two modes, and picking the wrong one bites you later.

ModeThe length meansChange the count and…
Extentthe total span, first to lastthey get closer together, span stays
Spacingthe gap between neighboursthe pattern gets longer

On the frame we use Extent, with the length and the count both coming from the spreadsheet. Change the number of tynes and the holes stay on the frame.

Occurrences includes the original. Nine means nine in total, not nine extra.

Patterns and Fasteners03 / 07

The limitation everybody hits

You cannot pattern a pattern

The tutorial patterns the holes nine times, then mirrors the pattern to the other bar. FreeCAD will not do the second step.

  • PartDesign cannot mirror a pattern, or pattern a mirror.
  • There is no error dialogue. The feature just goes grey and everything after it stops working.
  • The fix: do the symmetry inside the sketch, then pattern once.

The sketch route is arguably better anyway. The rear holes are tied to the front ones by a live rule, so they cannot drift apart.

Patterns and Fasteners04 / 07

Link arrays

Repeating a whole component

SolidWorks has a Linear Component Pattern. FreeCAD's Assembly does not — but links do it better.

  1. Select the component in the tree
  2. In the Data tab set Element Count
  3. Set Show Element to false
  4. Fill in the Placement List, one position per copy

Leave the link's own Placement alone. The list is measured from it, so if you set both, the whole row shifts. The parts look right next to each other but the rank is displaced from the frame.

Fasteners

The bolts we did not model

The tutorial calls for hex bolts from the SolidWorks Toolbox. FreeCAD has no bolt library built in.

OptionVerdict
Fasteners add-on — Tools, Addon Manager, install, restartthe right answer for real work
Model one bolt yourself — hexagon, pad, circle, padten minutes, and good sketching practice
Leave them outwhat we did, and said so

If you do add them: eighteen half-inch bolts, four inches long, hold the nine tynes on. That is the joint that matters.

Rules of thumb

  • Pattern the smallest thing that works. One pocket is robust; a group of six features is fragile.
  • Take the count and the spacing from the spreadsheet, never typed in.
  • Add fillets and chamfers after patterning, not before.
  • If a pattern or mirror goes grey, look for nesting first. Nine times out of ten that is what it is.
